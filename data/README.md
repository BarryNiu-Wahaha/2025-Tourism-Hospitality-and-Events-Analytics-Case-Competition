# Data

Place the original project data in `data/raw/`. These files are ignored by
Git because they may be proprietary or too large for a public repository.

The analysis uses:

- `Market_Daily_Exported.csv` for hotel performance metrics.
- `Market_Daily_SixGroup_Cleaned.csv` for season and concert-window labels.

Do not publish the raw data without permission. A small anonymized sample may
be added to `data/sample/` for reproducibility.
