## 1. Business Problem

### Research Question
> What is the economic impact of hosting a pop-star music concert?

The project evaluates how major concerts and music festivals
affect hotel market performance and translates the findings
into recommendations for hospitality and event stakeholders.


## 2. Data

- Atlanta

### Key Metrics

- Average Daily Rate (ADR)
- Revenue per Available Room (RevPAR)
- Room Demand
- Room Supply
- Room Revenue


## 3. Analytical Approach

### Event Window Analysis
Compare hotel performance:
- 7 days before
- During the event
- 7 days after

### Market Analysis
Compare event effects across cities.

### Hotel Segment Analysis
Compare performance across hotel classes.

### Event Type Analysis
Compare single-artist concerts with multi-day festivals.

### Seasonality Analysis
Evaluate whether concert effects vary by season.
